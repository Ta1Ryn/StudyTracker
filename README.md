# StudyTracker

Учебное консольное приложение для учёта курсов, пройденных тем и времени занятий.

## Что умеет

- 1 — добавлять курс с названием и общим количеством тем.
- 2 — показывать список курсов с номерами.
- 3 — отмечать одну тему выбранного курса пройденной.
- 4 — прибавлять минуты занятия к времени выбранного курса.
- 5 — показывать пройденные и оставшиеся темы, процент прохождения и суммарное время.
- 0 — завершать работу.

При запуске есть пример: «Основы C#» с 20 темами. Темы учитываются количеством.
Данные хранятся в памяти до закрытия приложения.

## Как запустить

Нужен .NET SDK 10. В терминале из папки проекта:

    dotnet run

## Как читать Program.cs

- В начале создаются список курсов и начальный курс.
- В конструкции switch находятся действия меню. Начни с case 1 и case 2,
  затем читай case 3, case 4 и case 5.
- ShowCourses выводит курсы по очереди.
- SelectCourse спрашивает номер и возвращает индекс курса в списке.
- ReadNumber проверяет ввод и повторяет вопрос при ошибке.
- В конце находится класс Course: описание данных одного курса.

## Проверить вручную

Добавь «Английский» с 3 темами. Отметь одну тему этого курса и запиши два занятия:
30 и 45 минут. В прогрессе «Английского» должны появиться 1 из 3 тем, примерно
33,3% и 75 минут. У «Основ C#» должны остаться 0 из 20 тем и 0 минут.
